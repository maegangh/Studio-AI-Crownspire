## 🎟️ SECTION I: SEASON ARCHITECTURE & ENGAGEMENT MATRIX

"The Sovereign Ledger" is the core seasonal monetization and engagement engine of **Crownspire**. It is designed around a **60-day seasonal cadence**, structuring clear, short-term daily loops and long-term milestones for players.

### 1. The Three Battle Pass Tracks
To maximize player accessibility while rewarding financial commitment, the Battle Pass features three distinct tracks:

```
+---------------------------------------------------------------------------------+
|                              THE THREE TIER TRACKS                              |
+---------------------------------------------------------------------------------+
| 🟢 FREE LEDGER     - Available to all accounts automatically.                   |
|                      Focuses on core resources, speedups, and base currency.     |
|                                                                                 |
| 🔵 PREMIUM LEDGER  - Unlocks for 950 Gems ($9.99).                              |
|                      Adds character skins, companion eggs, and equipment mats.  |
|                                                                                 |
| 🟣 ELITE LEDGER    - Unlocks for 2400 Gems ($24.99).                            |
|                      Instant +20 Tier skip, +25% XP modifier, Elite nameplate.   |
+---------------------------------------------------------------------------------+
```

- **Free Ledger:** Automatically unlocked for every governor at Level 1. Features an optimal supply of raw resources, build speedups, and common recruit tickets, serving as the baseline retention anchor.
- **Premium Ledger (950 Gems / $9.99):** Unlocks the secondary row of reward nodes. This track houses premium cosmetic assets, high-rarity commander gear materials, exclusive companion matching tokens, and the seasonal Hero.
- **Elite Ledger (2400 Gems / $24.99):** Designed for high-velocity players. Fully unlocks the Premium Ledger, instantly skips the first **20 levels (2,000 Battle Pass XP)**, grants a permanent **+25% seasonal XP multiplier** on all quests, and gives an exclusive animated profile frame and name tag.

### 2. Time-Scale & XP Mechanics
- **Season Length:** Exactly **60 Days**.
- **Level Requirements:** Each level requires exactly **100 Battle Pass XP**.
- **Total XP for Level 100:** Exactly **10,000 XP**.
- **XP Acquisition Caps:** Players can earn a maximum of **1,200 XP weekly** via Daily and Weekly Season Quests, ensuring consistent pacing throughout the 60-day cycle.

## 🚀 SECTION II: SEASONAL STORYLINE & COSMETIC THEMES

Each Battle Pass season operates under a distinct narrative theme that dictates the design of corresponding character skins, companions, and castle cosmetics.

### Season 1 Concept: "The Obsidian Sun"
As magma fractures open across the southern coordinates, the Keep is wrapped in a dramatic dark basalt aesthetic, contrasted by glowing magma seams and golden-crimson sunset lighting.

#### 🏰 Seasonal Castle Skin: "Obsidian Core Citadel"
*   **Art Direction:** The standard light limestone walls of the Citadel Keep are replaced with interlocking dark basalt plates. Molten lava flows along the walkways as gold-rimmed chimney stacks vent heart-shaped soot circles.
*   **Tier Placement:** Level 100 (Premium Ledger).

#### 🐉 Seasonal March Skin: "Draconic Smolder Trail"
*   **Art Direction:** Marching infantry, cavalry, and archers leave behind a trail of glowing ember footprints on map pathways. A small, translucent red dragon whelp circles the army vanguard as a scout guide.
*   **Tier Placement:** Level 50 (Premium Ledger).

#### 🦅 Seasonal Elite Hero: "Cinder-Marshal Brandon" (Command Specialist)
*   **Visual Design:** A rugged knight covered in burnished obsidian plate armor. His cape is woven from red volcanic embers, and his shield is a massive dragon skull.
*   **Abilities:** Grants a $+15\%$ defense boost to Infantry and Cavalry deployed near hot volcanic tiles.
*   **Tier Placement:** Level 1 (Premium Ledger).

#### 🥚 Seasonal Legendary Companion: "Radiant Emberlet"
*   **Aesthetic:** A round, plump fire-owl chick with a floating golden sun halo behind its head. Its feet are tiny copper cleats, and it hiccups small soot clouds when clicked.
*   **Tier Placement:** Level 80 (Premium Ledger).

## 🏃‍♂️ SECTION IV: SEASON QUEST ENGINE (THE ENGAGEMENT REEFS)

To progress through the 100 levels, players complete specific seasonal tasks divided into three distinct cycles.

### 1. Daily Quests (Refreshed at 00:00 UTC)
Consists of quick, habitual checklists. Each daily quest grants **+10 Battle Pass XP**.
*   **Keep Gathering:** Collect 10,000 raw resources within town borders.
*   **Frontier Patrol:** Complete 2 Hero Expedition dungeon campaigns.
*   **Garrison Drill:** Train 50 vanguard infantry, archer, or cavalry troopers.
*   **Alliance Pledge:** Help 5 alliance members with speed requests.

### 2. Weekly Quests (Refreshed every Monday)
Longer-term milestones rewarding consistent weekly engagement. Each yields **+50 Battle Pass XP**.
*   **Bedrock Excavation:** Harvest 150,000 Slate blocks from map quarries.
*   **Dragon Slayer:** Purge 15 Volcanic Ember Hatchlings on volcanic terrain paths.
*   **Blacksmith Furnace:** Forge 3 rare or epic weapon items at the smithy.
*   **Imperial Expansion:** Complete 3 building level advancements inside your keep.

### 3. Seasonal Milestones (Active across the 60 days)
Epic, long-term goals requiring coordination and master-level planning. Each yields **+200 Battle Pass XP**.
*   **Sovereign Apex:** Upgrade the Citadel Keep to level 25 or above.
*   **Titan Hunter:** Participate in 10 alliance rallies against *Sovereign Ignis the Volcanic Leviathan*.
*   **Grand Library:** Research 20 advanced technology lines in the Celestial observatory.
*   **Heroic Legend:** Raise the active power margin of any 2 commanders to level 50 or higher.

### 2. TypeScript Reward Claim Validation Controller (`src/utils/battlePassManager.ts`)
```typescript
export interface BattlePassUserRecord {
  xp: number;
  isPremium: boolean;
  claimedFree: number[];
  claimedPremium: number[];
}

export function getCurrentBattlePassLevel(xp: number): number {
  const level = Math.floor(xp / 100) + 1;
  return Math.min(100, level);
}

export function canClaimLevelReward(
  level: number,
  userRecord: BattlePassUserRecord,
  rewardType: 'free' | 'premium'
): { allowed: boolean; reason?: string } {
  const currentLvl = getCurrentBattlePassLevel(userRecord.xp);
  
  if (level > currentLvl) {
    return { allowed: false, reason: "Level not reached yet. Earn more Battle Pass XP." };
  }
  
  if (rewardType === 'free') {
    if (userRecord.claimedFree.includes(level)) {
      return { allowed: false, reason: "Free reward already claimed for this level." };
    }
    return { allowed: true };
  } else {
    if (!userRecord.isPremium) {
      return { allowed: false, reason: "Requires Premium Ledger upgrade." };
    }
    if (userRecord.claimedPremium.includes(level)) {
      return { allowed: false, reason: "Premium reward already claimed for this level." };
    }
    return { allowed: true };
  }
}
```
