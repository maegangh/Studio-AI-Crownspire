## 🎨 SECTION I: THE UNIVERSAL GENERATION FORMULA

To ensure perfect visual cohesion across different artists, outsourcing studios, and text-to-image generator models (e.g., Midjourney, Stable Diffusion XL, Imagen 3), all prompts must apply the **Master Rendering Formula**.

```
[ ASSET CATEGORY ] + [ DIRECT SUBJECT ] + [ MATERIAL COMPOSITION ] + [ LIGHTING & BLOOM SPEC ] + [ PERSPECTIVE / CAM ] + [ STYLE SUFFIX ]
```

### 1.1 Core Visual Keywords (The Style Anchors)
*   **The Material Palette:** `matte Calacatta marble with subtle grey-violet veins`, `polished Auric Sol-gold beveled trim (#E5A93B)`, `deep Abyssal Basalt shadows`, `translucent Celestial Blue nebula crystals`.
*   **The Render Quality:** `stylized 3D mobile game asset, extremely detailed, Unreal Engine 5 render, Octane Render style, high fidelity, 8k resolution, volumetric lighting, ray-traced shadows, physically based rendering (PBR) textures`.
*   **The Isolation Anchor (For UI/Icons/Tiles):** `isolated on a solid black background, centered composition, clean borders, no watermarks, no text, no human hands`.
